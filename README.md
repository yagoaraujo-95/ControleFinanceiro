# 💰 Controle Financeiro

Aplicação web desenvolvida para gerenciamento de receitas e despesas, permitindo ao usuário ter controle total sobre sua vida financeira de forma simples e prática.
Ainda em desenvolvimento.
---

## 🚀 Funcionalidades

- ✅ Adicionar receitas e despesas  
- 📊 Visualizar saldo total automaticamente  
- ❌ Remover transações  
- 💾 Armazenamento de dados no navegador (localStorage)  

---

## 🛠️ Tecnologias utilizadas

- HTML5  
- CSS3  
- JavaScript (Vanilla JS)
